# 磁场可视化网页 v2

面向高中课堂的七场景磁场演示网页。页面内部统一按 SI 制计算，界面使用 `cm`、`A`、`μT` 和 `mT`，并优先保证磁场方向、叠加关系、尺度规律和磁感线闭合正确。

## 运行

```bash
python3 serve.py
```

浏览器打开 <http://127.0.0.1:8081/>。Three.js 已放在 `vendor/`，运行不依赖 CDN 或外网。

## 单位与模型

- 几何内部单位：`1 = 0.1 m = 10 cm`。
- 磁场内部单位：`μT`；界面会自动切换 `μT`、`mT` 或 `T`。
- 地磁场：球外为精确偶极子主场；球内为与球外连续衔接、无散度的轴对称核心电流近似。
- 条形磁铁：均匀磁化长方体的表面磁荷数值积分。
- 弯折导线：三段可见有限直导线与后方远置回流线组成完整闭合回路，使用有限线段 Biot-Savart 公式。
- 通电直导线：有限半径导线解析解；导线外 `B∝1/r`，导线内 `B∝r`。
- 双导线：两根有限半径直导线场的矢量叠加，`I₁`、`I₂` 可独立调节。
- 环形电流：有限线径 Biot-Savart 数值积分，圆心和轴线用解析式交叉检查。
- 通电螺线管：48 层等效圆环的 Biot-Savart 直接叠加，参数保持 `L ≥ 2R`，中心、近端和管口均用有限长轴线公式交叉检查。

## 教学边界

这是物理自洽的课堂模型，不是有限元工程仿真。地球局部异常、铁磁材料的磁滞和非线性磁导率、绕组导线粗细、端部机械细节均不在本版本范围内。

热力图默认关闭，以排除场源内部后的截面 P98 作为色标上限。“仅显示截面”会对场的面内投影重新积分，不是裁剪三维线。代表性场线的数量和疏密只用于观察场形，不是经过磁通量标定的定量测量。

页面内置 `45` 项物理回归和场线质量门槛；当前物理与默认/参数边界几何组合验收结果为 `45/45` 与 `23/23`。

完整验收记录见 [VALIDATION.md](./VALIDATION.md)。
