# 磁场可视化网页

2026年9月13日版（课堂现场验收待完成）。七场景课堂仿真与教师端三维教室磁场地图，依赖全部随仓库保存。

## 运行

独立运行：`python3 serve.py`，打开 http://127.0.0.1:8081/ 。完整课堂材料包应使用根目录的启动脚本，端口为8765，课件与离线视频链接按该端口配置。

在线入口：https://jaccihan.github.io/magnetic-field-visualization-v2/

地图入口：`classroom-map.html`。每桌一名记录人、汇总人合并完整Excel、教师一次上传。数据保存在本机浏览器，不上传服务器。支持五列XLSX、CSV、三维方向、桌位选择、手工复测标记与数据导出。

表头：`横x桌,纵y桌,bx,by,bz`。桌位从1开始，磁场分量为东、北、上，单位μT。模板在templates。缺失不补零、零矢量无方向、错误导入保留原图。示例明确为模拟数据。

## 模型与单位

几何1单位等于10cm；B输出μT，界面自动显示μT/mT/T。

- 地磁：球外倾斜偶极主场，球内连续无散度近似。11.5度为教学参数。
- 条形磁铁：均匀磁化长方体端面的解析积分，材料界面不提供定量读数。
- 弯折导线：可见三段与后方回流线构成闭合路径，有限线段Biot–Savart场。
- 无限直导线：有限半径均匀电流圆柱内外解析式。
- 双导线：逐分量叠加，电流独立调节，保留单根导线的真实方向。
- 环形电流：384段Biot–Savart积分，近线芯正则化区域屏蔽定量读数。
- 螺线管：连续薄壁空气芯近似，变量代换后48点Gauss积分。忽略实际螺旋绕组的轴向电流、回路和铁芯，画面绕线为示意。

绘图线数不改变场强；二维投影重叠需要旋转辨别。教室地图仅展示离散采样值与方向，不据此重建完整空间磁感线。

## 验证

`npm test`执行83项回归测试，覆盖课堂数据、截面、独立物理参考、轨迹质量、后台任务及预计算资源。最新核验结果与边界见 [VALIDATION.md](./VALIDATION.md)。完整课堂包含独立数值、视频证据和待填写的现场验收表。

## 9月13日显示与计算调整

预测提示整块置于画布左上角。环形电流“清晰/标准/丰富”分别为2/4/6个子午面、16/40/72条磁感线。数值场函数与绘图密度无关。

`field-core.js`保存纯数值模型，`field-worker.js`在后台计算，`compute-client.js`取消过期任务。显隐复用当前结果；场参数或截面变化只重算需要的图层。计算失败时显示重试按钮。原生全屏不可用时采用铺满浏览器窗口的备用显示，可用退出按钮或Esc恢复。

螺线管使用36种允许尺寸的本地预计算文件（约6.4MB总计，按需加载），保留48点Gauss积分与原有追踪精度；电流和匝数按线性模型缩放场值，反向电流同时反转轨迹方向。非默认截面仍直接数值积分。Worker仅保留最近两个解码文件，缓存文件加载失败时回退后台计算，回退耗时不保证达到预计算性能指标。

修改数值核心后运行 `node scripts/build-solenoid-cache.mjs` 更新目录，再运行 `npm test`；测试会核对核心和每个缓存文件的SHA256，不能只替换JS却保留旧缓存。部署时必须完整包含新增模块、`precomputed/`、`vendor/`和`.nojekyll`。请通过本地HTTP启动，直接双击HTML不支持模块Worker。

在URL追加 `?qa=1` 可开启有限长度的帧率/长任务记录。页面DOM的 `data-last-render` 在Three.js提交渲染后记录计时；它不是显示器扫描输出的硬件测量。验收原始记录在项目同级 `需求0913/验收证据/`。本机测试不替代授课电脑、投影和发布后的复验。
